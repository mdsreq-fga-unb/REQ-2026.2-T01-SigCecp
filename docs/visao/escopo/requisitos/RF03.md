### RF03: Cadastrar turma

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Detalhado, v1.0 |
| **CP de origem** | CP1: Gestão e acompanhamento de turmas (ver [8.1](../../../historico/8_0_requisitos.md)) |
| **Declaração** | Deve ser possível à coordenação cadastrar turmas. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 3, Deveria ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Modalidade; dias e horários. **[PENDENTE]** demais campos (nome da turma, instrutor, limite de vagas) |
| **Pré-condições** | Coordenador autenticado |
| **Processamento** | Valida os campos obrigatórios e grava a turma |
| **Saídas** | Turma disponível para associação de alunos; mensagem de erro em caso de campo ausente |
| **Regras de negócio** | [RN22](../regras_de_negocio.md#rn22): o sistema inicia vazio, então cadastrar turma é a primeira ação necessária. |
| **RNFs aplicáveis** | RNF01, RNF03, RNF06, RNF11 (definições em [8.2](../../../historico/8_0_requisitos.md)) |
| **Critérios de aceitação** | 1. Dada uma turma com modalidade e horários, quando salva, então ela fica disponível para seleção no cadastro do aluno.<br>2. Dados campos obrigatórios ausentes, quando tenta salvar, então o sistema bloqueia e informa. |
