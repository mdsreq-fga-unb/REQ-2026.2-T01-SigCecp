### RF00: Encerrar sessão

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Detalhado, v1.0 |
| **CP de origem** | Acesso e controle de usuários (ver [8.1](../../../historico/8_0_requisitos.md)) |
| **Declaração** | Deve ser possível ao usuário autenticado encerrar sua sessão ativa no sistema, invalidando suas credenciais de acesso e redirecionando-o para a tela de login. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 4, Tem que ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Ação "Sair" |
| **Pré-condições** | Usuário autenticado |
| **Processamento** | Invalida a sessão ativa e suas credenciais e redireciona para a tela de login |
| **Saídas** | Sessão encerrada; tela de login exibida |
| **Regras de negócio** | [RN17](../regras_de_negocio.md#rn17): o encerramento é total; para voltar à área de coordenação é preciso informar usuário e senha novamente.<br>[RN18](../regras_de_negocio.md#rn18): na reunião o cliente admitiu redirecionar também para um modo público; a tela de login é o comportamento adotado. |
| **RNFs aplicáveis** | RNF11, RNF13 (definições em [8.2](../../../historico/8_0_requisitos.md)) |
| **Critérios de aceitação** | 1. Dado um usuário autenticado, quando clica em sair, então a sessão é invalidada e ele é redirecionado para a tela de login.<br>2. Dada uma sessão encerrada, quando tenta acessar uma funcionalidade administrativa, então o sistema exige nova autenticação. |
