### RF00: Encerrar sessão

[Ver no painel do escopo](../../../painel.md#RF00)

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Validado, v1.2 |
| **CP de origem** | Acesso e controle de usuários (ver [2.3](../../contexto/2_solucao_proposta.md)) |
| **Declaração** | Deve ser possível ao usuário autenticado encerrar sua sessão ativa no sistema, invalidando suas credenciais de acesso e redirecionando-o para a tela de login. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 4, Tem que ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Ação "Sair" |
| **Pré-condições** | Usuário autenticado |
| **Processamento** | Invalida a sessão ativa e suas credenciais e redireciona para a tela de login |
| **Saídas** | Sessão encerrada; tela de login exibida |
| **Regras de negócio** | [RN17](../../../painel.md#RN17): o encerramento é total; para voltar à área de coordenação é preciso informar usuário e senha novamente.<br>[RN18](../../../painel.md#RN18): na reunião o cliente admitiu redirecionar também para um modo público; a tela de login é o comportamento adotado. |
| **RNFs aplicáveis** | [RNF11](../rnf/RNF11.md), [RNF13](../rnf/RNF13.md) (definições nas fichas de RNF) |
| **Critérios de aceitação** | 1. Dado um usuário autenticado, quando clica em sair, então a sessão é invalidada e ele é redirecionado para a tela de login.<br>2. Dada uma sessão encerrada, quando tenta acessar uma funcionalidade administrativa, então o sistema exige nova autenticação. |
| **Origem e decisões** | [DEC04](../../../painel.md#DEC04): redirecionamento para a tela de login, confirmado no protótipo apresentado em 10/11/2026<br>[DEC20](../../../painel.md#DEC20): protótipo aprovado pelo cliente em 10/11/2026; o retorno das demais pessoas do CECP também foi positivo<br>[DEC19](../../../painel.md#DEC19): testado e aceito pelo cliente em 10/11/2026 |
