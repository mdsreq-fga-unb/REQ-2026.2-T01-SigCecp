### RF20: Consultar eventos

[Ver no painel do escopo](../../../painel.md#RF20)

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Validado, v1.3 |
| **CP de origem** | CP3: Gestão de conteúdo institucional (ver [2.3](../../contexto/2_solucao_proposta.md)) |
| **Declaração** | Deve ser possível consultar os eventos ou campeonatos já publicados, em uma listagem que indique o estado de cada um. |
| **Ator principal** | Visitante (consulta pública, sem login) e coordenação (acesso às ações de editar e remover) |
| **Valor de negócio (MoSCoW)** | 3, Deveria ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Acesso à listagem de eventos |
| **Pré-condições** | Existir ao menos um evento publicado. Não exige autenticação para visitantes |
| **Processamento** | Recupera os eventos, calcula o estado de cada um e os exibe em lista; a coordenação acessa também as opções de editar e remover |
| **Saídas** | Lista com título, data, local e estado (Em breve, Em andamento, Encerrado); detalhes completos ao selecionar um evento |
| **Regras de negócio** | [RN33](../../../painel.md#RN33): os estados possíveis são Em breve (ainda vai ocorrer), Em andamento (está ocorrendo) e Encerrado (já ocorreu). |
| **RNFs aplicáveis** | [RNF02](../rnf/RNF02.md), [RNF07](../rnf/RNF07.md), [RNF09](../rnf/RNF09.md) (definições nas fichas de RNF) |
| **Critérios de aceitação** | 1. Dado um visitante, quando acessa a listagem, então vê eventos futuros, em andamento e encerrados, cada um com seu estado.<br>2. Dado um evento cuja data já passou, quando listado, então aparece como Encerrado.<br>3. Dado um coordenador autenticado, quando consulta um evento, então tem acesso às ações de editar e remover.<br>4. Dada uma imagem exibida, quando o visitante clica nela, então ela é mostrada ampliada (pedido do cliente em 10/11, ainda a construir). |
| **Origem e decisões** | Imagem expansível ao clicar, pedida pelo cliente no teste de 10/11/2026 |
