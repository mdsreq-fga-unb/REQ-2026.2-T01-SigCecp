### RF06: Associar aluno à turma

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Detalhado, v1.0 |
| **CP de origem** | CP1: Gestão e acompanhamento de turmas (ver [8.1](../../../historico/8_0_requisitos.md)) |
| **Declaração** | Deve ser possível associar um aluno a uma turma (modalidade, dias e horários). |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 3, Deveria ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Aluno; turma |
| **Pré-condições** | Aluno e turma cadastrados |
| **Processamento** | Vincula o aluno à turma escolhida. |
| **Saídas** | Aluno vinculado à turma |
| **Regras de negócio** | [RN23](../regras_de_negocio.md#rn23): modalidade, dias e horários fazem parte da ficha do aluno. |
| **RNFs aplicáveis** | RNF03, RNF04, RNF06, RNF11 (definições em [8.2](../../../historico/8_0_requisitos.md)) |
| **Critérios de aceitação** | 1. Dados um aluno e uma turma existentes, quando a coordenação os associa, então o aluno aparece vinculado à turma.<br>2. Dado o cadastro de um aluno, então é possível escolher a turma na própria ficha. |
