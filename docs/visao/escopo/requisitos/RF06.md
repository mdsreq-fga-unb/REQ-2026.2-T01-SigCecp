### RF06: Associar aluno à turma

[Ver no painel do escopo](../../../painel.md#RF06)

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Validado, v1.2 |
| **CP de origem** | CP1: Gestão e acompanhamento de turmas (ver [2.3](../../contexto/2_solucao_proposta.md)) |
| **Declaração** | Deve ser possível associar um aluno a uma turma (modalidade, dias e horários). |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 3, Deveria ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Aluno; turma |
| **Pré-condições** | Aluno e turma cadastrados |
| **Processamento** | Vincula o aluno à turma escolhida. |
| **Saídas** | Aluno vinculado à turma |
| **Regras de negócio** | [RN23](../../../painel.md#RN23): modalidade, dias e horários fazem parte da ficha do aluno.<br>[RN22](../../../painel.md#RN22): a turma precisa existir antes; sem turma cadastrada, não é possível associar o aluno. |
| **RNFs aplicáveis** | [RNF03](../rnf/RNF03.md), [RNF06](../rnf/RNF06.md), [RNF11](../rnf/RNF11.md) (definições nas fichas de RNF) |
| **Critérios de aceitação** | 1. Dados um aluno e uma turma existentes, quando a coordenação os associa, então o aluno aparece vinculado à turma.<br>2. Dado o cadastro de um aluno, então é possível escolher a turma na própria ficha.<br>3. Dada uma turma sem alunos, quando a coordenação seleciona um aluno já cadastrado, então ele passa a constar na turma. |
| **Origem e decisões** | Protótipo aprovado pelo cliente em 10/11/2026; o retorno das demais pessoas do CECP também foi positivo |
