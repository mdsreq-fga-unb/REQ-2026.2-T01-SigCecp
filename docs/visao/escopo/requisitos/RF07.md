### RF07: Consultar alunos de uma turma

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Detalhado, v1.0 |
| **CP de origem** | CP1: Gestão e acompanhamento de turmas (ver [8.1](../../../historico/8_0_requisitos.md)) |
| **Declaração** | Deve ser possível à coordenação consultar os alunos que fazem parte de uma turma específica. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 4, Tem que ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Seleção da turma |
| **Pré-condições** | Turma cadastrada; coordenador autenticado |
| **Processamento** | Busca os alunos associados à turma e exibe a listagem; ao selecionar um aluno, abre a ficha (RF23) |
| **Saídas** | Lista de alunos da turma (foto e nome completo) |
| **Regras de negócio** | [RN24](../regras_de_negocio.md#rn24): a listagem de alunos segue o padrão mostrado na reunião (foto e nome completo). **[PENDENTE]** definir se alunos inativos aparecem na lista da turma. |
| **RNFs aplicáveis** | RNF01, RNF06, RNF11 (definições em [8.2](../../../historico/8_0_requisitos.md)) |
| **Critérios de aceitação** | 1. Dada uma turma com alunos associados, quando a coordenação a seleciona, então o sistema lista os alunos da turma.<br>2. Dada uma turma sem alunos, quando consultada, então o sistema informa que não há alunos associados. |
