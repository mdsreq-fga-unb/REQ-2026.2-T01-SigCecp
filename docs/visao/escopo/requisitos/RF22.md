### RF22: Editar aluno

[Ver no painel do escopo](../../../painel.md#RF22)

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Detalhado, v1.0 |
| **CP de origem** | CP4: Cadastro e histórico de alunos (ver [2.3](../../contexto/2_solucao_proposta.md)) |
| **Declaração** | Deve ser possível à coordenação editar os dados do aluno e acrescentar documentos posteriormente. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 4, Tem que ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Qualquer campo da ficha; anexos (imagens digitalizadas, textos) |
| **Pré-condições** | Aluno cadastrado; coordenador autenticado |
| **Processamento** | Valida e atualiza os dados e armazena os novos anexos |
| **Saídas** | Ficha atualizada; mensagem de erro se um campo obrigatório for esvaziado |
| **Regras de negócio** | [RN41](../../../painel.md#RN41): a edição serve principalmente para completar documentos pendentes (laudo, certificado, atestado, foto 3x4, comprovante).<br>[RN42](../../../painel.md#RN42): os documentos podem ser anexados como imagem digitalizada ou pdf.<br>[RN43](../../../painel.md#RN43): a edição preserva as regras de obrigatoriedade do cadastro (RF21). |
| **RNFs aplicáveis** | [RNF03](../rnf/RNF03.md), [RNF06](../rnf/RNF06.md), [RNF10](../rnf/RNF10.md), [RNF11](../rnf/RNF11.md), [RNF13](../rnf/RNF13.md) (definições nas fichas de RNF) |
| **Critérios de aceitação** | 1. Dado um aluno sem laudo, quando a coordenação anexa o laudo, então ele passa a constar na ficha.<br>2. Dada a edição de um campo obrigatório para vazio, quando tenta salvar, então o sistema bloqueia. |
