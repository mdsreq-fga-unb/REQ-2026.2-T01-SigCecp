### RF19: Remover evento

[Ver no painel do escopo](../../../painel.md#RF19)

| Campo | Descrição |
| :--- | :--- |
| **Estado e versão** | Validado, v1.1 |
| **CP de origem** | CP3: Gestão de conteúdo institucional (ver [2.3](../../contexto/2_solucao_proposta.md)) |
| **Declaração** | Deve ser possível à coordenação remover um evento ou campeonato. |
| **Ator principal** | Coordenação |
| **Valor de negócio (MoSCoW)** | 3, Deveria ter · MVP (ver [priorização](../../../historico/priorizacao_geral_e_mvp.md)) |
| **Entradas** | Identificação do evento; confirmação da remoção |
| **Pré-condições** | Coordenador autenticado; evento existente |
| **Processamento** | Solicita confirmação e exclui o evento e seus anexos |
| **Saídas** | Confirmação da remoção; evento deixa de ser exibido |
| **Regras de negócio** | [RN26](../../../painel.md#RN26) (ver RF13).<br>[RN30](../../../painel.md#RN30): a remoção é total e definitiva. |
| **RNFs aplicáveis** | [RNF02](../rnf/RNF02.md), [RNF05](../rnf/RNF05.md), [RNF07](../rnf/RNF07.md), [RNF09](../rnf/RNF09.md), [RNF10](../rnf/RNF10.md) (definições nas fichas de RNF) |
| **Critérios de aceitação** | 1. Dado um evento publicado, quando a coordenação confirma a remoção, então ele deixa de aparecer em qualquer listagem.<br>2. Dado um usuário sem perfil de coordenação, quando tenta remover, então o sistema nega a operação. |
| **Origem e decisões** | [DEC02](../../../painel.md#DEC02): confirmação antes de ações críticas |
