### RNF01: Facilidade de aprendizado

| Campo | Descrição |
| :--- | :--- |
| **Classificação (URPS+)** | Usabilidade (U) |
| **Descrição** | Interface que permite ao usuário realizar tarefas sem precisar de muito tempo de aprendizado ou treinamento para voluntários sem experiência técnica (CP1, CP3, CP4, CP5). |
| **Critério de aceitação** | Usuários novatos no sistema deverão conseguir realizar as tarefas após de se familiarizarem com o sistema por no máximo 8 minutos. 80% dos usuários devem cumprir as tarefas para ser aceito. |
| **CP de origem** | CP1, CP3, CP4, CP5 (ver [8.1](../../../historico/8_0_requisitos.md)) |
