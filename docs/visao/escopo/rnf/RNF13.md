### RNF13: Conformidade com a LGPD

| Campo | Descrição |
| :--- | :--- |
| **Classificação (URPS+)** | + Segurança |
| **Descrição** | O sistema deve tratar os dados pessoais de acordo com os princípios, direitos dos titulares e requisitos de segurança e tratamento estabelecidos pela Lei nº 13.709/2018 (LGPD). |
| **Critério de aceitação** | O sistema deve permitir o atendimento às solicitações aplicáveis dos titulares ou responsáveis legais relacionadas aos seus dados pessoais, incluindo solicitação de eliminação quando cabível, além de classificar e proteger dados pessoais sensíveis conforme a LGPD. |
